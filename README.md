# NexusProxy

**[Скачать последнюю версию](https://github.com/hipocrisle/nexusproxy/releases/latest)** —
установщик `NexusProxy_*_x64-setup.exe`. Ставится в профиль пользователя,
права администратора не нужны. Рядом лежит `NexusProxy.exe` — то же самое
без установки.

Выбранные ресурсы идут через вышестоящий SOCKS5, всё остальное — напрямую.
Бесплатная замена Proxifier для тех случаев, когда доступ к нужным сервисам
есть только через корпоративный прокси.

**Прав администратора не требует.** Настройки пишутся только в профиль
текущего пользователя, ничего не устанавливается в систему.

## Из чего состоит

| Часть | Что делает |
|---|---|
| `core/` | движок: HTTP и SOCKS5 входы, правила, клиент вышестоящего прокси |
| `app/` | окно программы на Tauri: правила, подбор доменов, журнал, настройки |
| `windows/` | комплект для проверки: консольная версия движка |

Движок собран как библиотека, ею пользуются и окно, и консольная версия.

## Почему не готовые движки

Xray, sing-box и подобные не подходят: их бинарники ловит антивирус на
рабочих машинах и выглядят они как средства обхода блокировок. Здесь свой
код, единственная зависимость — tokio.

## Ключевые решения

**Два входа сразу — HTTP и SOCKS5.** Claude Code документированно не
поддерживает SOCKS, только HTTP. Codex умеет оба. Без HTTP-входа половина
инструментов разработчика молча не подключится.

**По умолчанию всё идёт напрямую.** Через прокси уходит только явно
перечисленное. В настройках xray обратный порядок, и на этом легко
потерять весь трафик — здесь так не выйдет.

**Подбор доменов с отсечением фона.** Сервисы тянут данные с соседних
доменов: у ChatGPT это `oaistatic.com`, у 2ip.ru — `2ip.io`. Правило по
одному имени их не покрывает, и сервис работает наполовину. Программа
записывает, что пошло напрямую сразу после обращений через прокси, и
отбрасывает всё, что видела до начала подбора — так отсеиваются
мониторинг, реклама и прочий постоянный фон.

## Обновления

Программа проверяет обновления сама и ставит их без прав администратора.
Если сеть закрыта периметром, окно покажет, какие адреса нужно пустить
через прокси, и предложит добавить их одной кнопкой.

## Сборка

```bash
cd core && cargo test          # 23 теста
./build-windows.sh             # консольный движок под Windows
./build-app-windows.sh         # окно программы под Windows
```

Обе сборки идут в контейнере, на машину ничего не ставится.
