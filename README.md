# NexusProxy

Выборочное проксирование для Windows и macOS: выбранные программы и
адреса идут через вышестоящий прокси, всё остальное — напрямую.

**[Скачать последнюю версию](https://github.com/hipocrisle/nexusproxy/releases/latest)**
— `NexusProxy_*_x64-setup.exe` для Windows, `NexusProxy_*_universal.dmg`
для macOS.

## Два способа работы

**Режим прокси.** Программа поднимает у себя HTTP- и SOCKS5-вход и
прописывает их в системные настройки. Подходит для всего, что эти
настройки читает. Прав администратора не требует.

**Режим перехвата.** Трафик выбранных программ забирается независимо от
того, умеют ли они работать через прокси. Нужен таким, как Cursor: он
ходит мимо системных настроек, и обычным способом его не поймать.

Перехват создаёт сетевой интерфейс, а это можно только с правами
администратора. Поэтому работает он службой от имени системы: права
спрашиваются **один раз**, при её установке. Дальше перехват включается и
выключается без них — в том числе у людей, у которых прав администратора
нет вовсе.

## Что настраивается

**Прокси.** Адрес, порт, логин и пароль. Можно завести несколько и
указывать для каждого правила свой.

**Правила по адресам.** Домен с поддоменами, точное имя, подстрока или
подсеть:

```
example.com          домен и все его поддомены
full:host.example    только это имя
keyword:openai       любое имя, содержащее «openai»
ip:10.0.0.0/8        подсеть
```

Строки, начинающиеся с `#` и `_`, — заметки и заголовки разделов.

**Программы.** Список программ, чей трафик идёт через прокси целиком.
Работает в режиме перехвата.

**Подбор доменов.** Показывает, что ушло напрямую. «Начать запись»
запоминает нынешний список и дальше показывает только новое — так видно,
куда лезет одна конкретная программа. Нужное добавляется в правила
кнопкой.

## Порядок действий

1. Поставить программу и открыть её.
2. В настройках вписать адрес прокси.
3. Добавить правила по адресам, а для программ, которые ходят мимо
   системных настроек, — включить режим перехвата и добавить их в список
   программ. При включении перехвата один раз спросят права
   администратора.
4. Проверить на вкладке «Соединения», что нужное идёт через прокси.

## Перенос настроек на другие машины

В настройках есть выгрузка и приём файла с прокси, правилами и группами.
Пароли прокси в него **не** попадают — их вписывают на месте. Список
программ тоже не переносится: пути у каждого свои.

## Обновления

Программа проверяет их сама и ставит без прав администратора. Права
спросят только если изменилась сама служба перехвата.

## Устройство

| Часть | Что делает |
|---|---|
| `core/` | движок: входы, правила, учёт, служба перехвата |
| `app/` | окно программы на Tauri |
| `windows/` | консольная версия движка для проверки |

Перехват трафика делает sing-box — он скачивается при первом включении и
работает под управлением службы.

## Сборка

```bash
cd core && cargo test      # 147 тестов
./check-windows.sh         # проверка сборки под Windows без полной сборки
./build-app-windows.sh     # окно программы под Windows
```

Выпуски собираются по тегу `vX.Y.Z`.
